# Pedro Ross

**`Full-Stack Developer | Founder @ LaborWaze`**

I'm Pedro Henrique Rodrigues Ross, a full-stack developer from São Paulo, Brazil. I build web and mobile apps, from the interface to the API and the database, mostly with React, React Native, Next.js, Node.js and NestJS.

I founded **LaborWaze**, a technology company where we build complete systems and record how they are made, from the technical decisions to the problems along the way, on our [YouTube channel](https://www.youtube.com/@LaborWaze). Projects and professional updates also go on my [LinkedIn](https://www.linkedin.com/in/pedro-ross).
